# TYPELITE
Why nobody prioritizes minimalism of primitive concepts?

# Drop-in use
You can take and drop the headers into your project. what you get:

- intrinsics (intrinsics.hpp)
- types (types.hpp)
- concepts  (concepts.hpp)
- bit-types (bit_types.hpp - my experimental universal primitive types system)
